## 👩‍💻 About the Project

This project is a frontend-focused personal portfolio website designed to present my technical journey and projects in a clean and modern interface.

The website was developed using **HTML, CSS, and JavaScript** with an emphasis on responsive design, interactive components, browser storage, and dynamic content handling.

---

## ✨ Features

- 🎨 Modern dark-themed UI
- 🌓 Light/Dark theme toggle
- 📱 Responsive design
- 🧭 Navigation bar with section links
- 👩‍💻 Personal profile and introduction
- 🛠️ Technical skills section
- 📂 Projects showcase
- 🏆 Achievements section
- 🎓 Education section
- 📩 Working Contact Me form
- 💾 Contact responses stored in `localStorage`
- 📋 Responses stored in JSON format
- 🔐 Admin login system
- 👀 Dynamic user response retrieval
- ⏰ Response timestamps
- 🗑️ Clear stored responses
- 🚪 Admin logout functionality
- 🚀 GitHub Pages deployment
